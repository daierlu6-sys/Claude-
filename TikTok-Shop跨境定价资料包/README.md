## 🎯 核心功能

### 一、快速计价
输入三个数据 → 自动得出所有定价结果
- **输入**：采购成本 + 重量 + 国内运费
- **输出**：保本售价 | 建议售价 | 单店利润 | 利润率

### 二、完整成本分解
清晰展示每一笔费用的来源和占比
- 产品拿货成本
- 国内运费
- 货代费用
- 跨境物流费
- 平台佣金（自动按国家计算）
- 交易手续费
- 关税
- 广告投放预算
- 退货损耗率

### 三、多国对比
一张表对比5个国家定价差异，找出最优销售国家

### 四、盈利预测
基于销量和利润率，预测月度利润
