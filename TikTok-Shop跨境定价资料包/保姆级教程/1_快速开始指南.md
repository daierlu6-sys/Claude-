## 5 分钟快速上手（三步走）

### 第 1 步：准备数据（1 分钟）

找到你要销售的商品，获取以下 3 个信息：

#### ① 采购成本（¥）
**去哪里查？**
- 1688.com 搜你的商品
- 询问供应商
- 看采购发票

**示例**：
```
你要卖：T恤衫
工厂价：25¥/件
→ 采购成本 = 25¥
```

#### ② 商品重量（KG）
**去哪里查？**
- 用电子秤称一下
- 看商品规格表
- 问供应商

**示例**：
```
T恤重量：300克
→ 商品重量 = 0.3 KG
```

#### ③ 国内运费（¥）
**去哪里查？**
- 问快递公司（申通、韵达等）
- 工厂到你的集运仓
- 通常 2-10¥

**示例**：
```
广州到深圳：3¥
→ 国内运费 = 3¥
```

## 最常见的定价问题

### Q1：为什么建议售价这么高？

**通常原因**：
1. 采购成本高
2. 运费高
3. 关税高

**怎么办**：
```
想办法降成本：
✓ 找更便宜的供应商
✓ 优化包装，减轻重量
✓ 拼车送到集运仓，降运费
```

---

### Q2：竞品卖得比建议价便宜，我怎么办？

**可能情况**：
1. 他们的成本比你低
2. 他们在亏本冲销量
3. 不同的品质

**怎么办**：
```
选项 A：降低你的成本
- 找工厂谈更便宜的价格
- 大批量进货享受折扣

选项 B：走差异化路线
- 宣传你的品质更好
- 突出你的特色（比如颜色多）
- 定价可以高一些

选项 C：换个国家卖
- 这个国家竞争太激烈
- 试试泰国、新加坡
```

---

### Q3：定价 100¥，利润率才 5%，值不值得卖？

**判断标准**：

| 利润率 | 值得吗? | 建议 |
|--------|--------|------|
| <10% | ❌ 不值 | 别卖，换品类 |
| 10-20% | ⚠️ 一般 | 如果销量大可以 |
| 20-40% | ✅ 可以 | 很不错 |
| 40%+ | 🟢 优秀 | 尽快铺货 |

### ✅ 定价 完成后的检查清单

```

     建议价 ±10% 范围内定价

```

## 模板中不用改的东西

❌ **不要改这些**（已经配置好）：
- 平台佣金率（系统规定）
- 关税率（海关规定）
- 物流费（物流商定价）

✅ **可以改这些**（根据实际调整）：
- 采购成本（进货价不同）
- 重量（商品不同）
- 国内运费（快递不同）
- 广告预算比例（新店 20%，老店 5-10%）

## 新手最容易犯的 5 个错误

### ❌ 错误 1：输入了毛重而不是净重
```
毛重（带包装）：500克
净重（只有产品）：300克
→ 应该输入 300 克（不带包装）
```

### ❌ 错误 2：国内运费算得太便宜
```
理想情况：2¥
实际情况：5¥ (包括搬运、分拣等)
→ 别遗漏隐形费用
```

### ❌ 错误 3：只看建议价，不看竞品价
```
正确流程：
建议价 120¥ → 竞品都卖 80¥
→ 你需要降成本，或换品类
```

### ❌ 错误 4：被高利润率迷惑
```
利润率 60% 看起来很高
但销量为 0，一分钱赚不到
→ 要平衡利润率和销量
```

### ❌ 错误 5：定价后从不更新
```
半年前定的价
现在竞品都便宜了 20%
→ 要每月检查一次竞品价格
```

## 核心要点再强调一遍

### 最简单的定价流程

```
1️⃣ 输入采购成本、重量、国内运费
       ↓
2️⃣ 选择销售国家
       ↓
3️⃣ 看"建议售价"
       ↓
4️⃣ 去 TikTok 查竞品价格
       ↓
5️⃣ 定价
       ↓
6️⃣ 上架销售
```

### 记住这个公式

```
利润 = 定价 - 所有成本

所有成本 = 拿货 + 运费 + 关税 + 平台费 + 广告费 + 损耗

利润率 = 利润 ÷ 定价
```
