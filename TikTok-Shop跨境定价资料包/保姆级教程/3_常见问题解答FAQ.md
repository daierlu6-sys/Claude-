# ❓ 常见问题解答 FAQ

## 定价相关问题

### Q1：为什么同样的商品在不同国家利润率差这么多？

**A：因为费率和消费力差异很大**

```
费率差异：
新加坡 7% + 0% 关税 = 7%（最低）
菲律宾 8.5% + 12% VAT = 20.5%（最高）

结果：同样成本 100¥
新加坡需定 200¥（利润 50%）
菲律宾需定 300¥（利润 33%）

建议：
优先销售高利润国家
```

---

### Q2：建议售价 500¥，竞品都卖 300¥，我怎么办？

**A：说明这个品类在这个国家竞争激烈**

```
原因可能：
❌ 你的成本比竞品高
❌ 竞品在亏本冲销量
❌ 商品质量有差异
✓ 竞品拿货渠道更便宜

解决方案：
□ 方案 A：降低成本
  向供应商谈价（多买可以便宜）
  
□ 方案 B：改为走量
  定价 350¥，接受 15% 利润率
  靠销量赚钱
  
□ 方案 C：走差异化
  强调你的品质、设计、售后
  定价可以高一些
  
□ 方案 D：换个国家
  这个国家不适合
  试试其他国家
```

---

### Q3：我刚开店，应该定价高还是低？

**A：定价应该科学，不用非得低**

```
新店常见误区：
❌ "新店就要低价吸引"
❌ 结果利润太低，收不回推广成本
❌ 积累了销量却亏钱

正确做法：
✓ 用建议价定价
✓ 前期加大广告投入（15-20%）
✓ 通过优质服务获得好评
✓ 好评多了，销量自然来
```

---

### Q4：为什么有些卖家能比我便宜这么多？

**A：可能是以下原因**

```
原因 1：拿货渠道不同
- 工厂直接拿货 vs 贸易商拿货
- 价格可能相差 20-50%
- 或大批量优惠

原因 2：成本控制不同
- 别人优化了物流和包装
- 减少了中间环节
- 每件省 2-5¥

原因 3：其他国家或品类
- 他们可能卖不同品类
- 不同国家费率也不同

原因 4：亏本冲销量
- 有人在烧钱抢市场
- 这不是长期可持续的

不要盲目跟风降价！
```

---

### Q5：我怎么知道我的定价是否合理？

**A：用这个检查清单**

```
□ 1. 成本分析
    建议售价 > 保本售价 + 合理利润
    
□ 2. 竞品对标
    定价在竞品 ±15% 范围内
    
□ 3. 利润率检查
    利润率 > 15%（至少这个水平）
    
□ 4. 市场可行性
    消费者愿意买这个价格吗？
    
□ 5. 长期可持续性
    这个利润能持续赚钱吗？
    
全部通过 = 定价合理 ✓
有 1-2 个未通过 = 需要调整
```

## 费率和成本问题

### Q6：关税怎么算？是多少？

**A：关税取决于商品品类和国家**

```
查询步骤：
1. 确定你的商品属于什么 HS 编码
2. 查询对应国家的关税表
3. 找到关税率

快速参考（常见品类）：
- 服装：马来 15-25%、新加坡 0-5%
- 电子：马来 5-15%、新加坡 0%
- 化妆：马来 10-15%、新加坡 5-8%

不同国家可能 3-5 倍差异！
```

---

### Q7：运费多少钱？怎么选物流？

**A：看重量和时间要求**

```
选择矩阵：

轻件（<1KG）+ 不急：邮政小包最便宜
轻件（<1KG）+ 要快：专线物流
重件（>5KG）+ 不急：海派物流
重件（>5KG）+ 要快：快递公司

国家特色：
新加坡：物流最便宜（邮政 12¥）
越南：物流较贵（邮政 20¥）
```

---

### Q8：平台费为什么这么高？能降吗？

**A：平台费是系统规定，新店可能有优惠**

```
规定费率（无法改变）：
- 马来/泰/越/新 5% 佣金 + 2% 手续费
- 菲律宾 6% 佣金 + 2.5% 手续费

可能的优惠：
- 新店前 3 个月 3-4% 佣金
- 重点品类扶持 3-4% 佣金
- 参加平台活动可能有减免

加入方法：
1. 咨询平台官方客服
2. 查看平台最新公告
3. 询问品牌合作团队
```

---

### Q9：增值税要自己承担吗？

**A：取决于品类和国家**

```
出口豁免的情况：
✓ 新加坡 GST 出口豁免
✓ 泰国 VAT 部分出口豁免
✓ 越南 VAT 原则上出口豁免

需要自承的情况：
❌ 菲律宾 VAT 12% 无法豁免
❌ 某些品类可能无法豁免
❌ 申报手续不全时无法豁免

建议：
咨询平台官方或当地税务
提供必要文件可能获得豁免
```

## 销量和利润问题

### Q10：定价 100¥，但销量为 0，怎么办？

**A：价格太高或其他因素**

```
检查清单：
□ 商品品质？（太低？）
□ 商品图片？（不吸引人？）
□ 商品描述？（没有亮点？）
□ 定价？（比竞品贵？）
□ 运费？（运费太贵？）
□ 配送时间？（太慢？）

改进方向：
1. 优化商品详情页
2. 参加平台活动增加曝光
3. 适当降价试试（降 10-15%）
4. 找到销量好的竞品学习
```

---

### Q11：为了冲销量，可以亏本卖吗？

**A：短期可以，长期不行**

```
什么是合理的亏本卖？
- 利润率：正常 20%，推广期 5-10%
- 目的：快速积累销量和评价
- 时间：前 1-3 个月
- 目标：之后恢复正常定价

什么是不合理的亏本卖？
❌ 利润率 <0%（确实亏钱）
❌ 长期持续亏本卖
❌ 为了打败竞争对手而亏本
❌ 没有明确的回本计划

建议：
降价吸量 OK，但要算清楚
什么时候回本、回本后怎么做
```

---

### Q12：月销 100 件，定价 200¥，能赚多少钱？

**A：用这个公式**

```
假设：
定价：200¥
利润率：30%
单件利润：200 × 30% = 60¥

月销 100 件：
月利润 = 60¥ × 100 = 6000¥

注意：
这是净利润（扣除所有成本）
还要减去：
- 店铺运营成本
- 售后问题损失
- 其他杂费

实际到手：4000-5000¥ 左右
```

## 商品和定价问题

### Q13：有多个 SKU（不同颜色/尺码），怎么定价？

**A：分别定价，但要保持一致性**

```
案例：T 恤有红/蓝/黑 三种颜色

如果成本不同：
红色：25¥ → 建议 200¥
蓝色：25¥ → 建议 200¥
黑色：30¥ → 建议 210¥

如果成本相同：
全部定 200¥（保持价格一致）

建议：
- 同一品类最多不超过 3 个价格档位
- 价格梯度 20-30%
- 避免价格混乱
```

---

### Q14：品牌/品质不同的同类商品，怎么定价？

**A：分开上架，高端卖高价**

```
例：手机壳

低端品质：20¥成本 → 定 100¥
中端品质：30¥成本 → 定 150¥
高端品质：50¥成本 → 定 250¥

各自优化定价和运营
目标客户不同
不要硬生生竞争
```

---

### Q15：季节性商品怎么定价？

**A：分阶段定价**

```
例：泳衣（夏季热卖）

旺季（5-8月）：
定价：150¥（高价）
备货：加大库存
销量目标：尽可能多

淡季（11-3月）：
定价：100¥（降价清库）
备货：减少订单
销量目标：清理库存

其他季节（4月、9-10月）：
定价：120¥（中价）
备货：适量
销量目标：保持曝光
```

## 模板和工具问题

### Q16：模板显示错误（#VALUE! 或 #REF!），怎么办？

**A：通常是数据输入错误**

```
排查步骤：
1. 检查 B1-B3 是否都输入了数字
2. 检查是否含有其他字符（¥、单位等）
3. 检查公式所引用的单元格是否存在
4. 重新输入一遍，不复制

如果还是错：
- 重新下载模板
- 或根据 2_Excel模板详细说明.md 自己建
```

```
示例：

预期月销量：100 件
预期月利润：5000¥

注意：这是理想情况
实际可能达不到
```

## 国家选择问题

### Q19：我应该选择哪个国家销售？

**A：根据你的优势选择**

```
新加坡 🇸🇬：利润最高
- 建议如果：你的商品质量好、成本可控
- 不建议如果：低端商品、薄利产品
- 预期：单店利润最高，但销量可能少

泰国 🇹🇭：平衡选择
- 建议如果：你想平衡利润和销量
- 不建议如果：全新手，不知道怎么选
- 预期：中等利润，中等销量

越南 🇻🇳：市场大
- 建议如果：你想要大销量，可以走量
- 不建议如果：你只想赚高利润
- 预期：低利润，大销量

菲律宾 🇵🇭：直播电商
- 建议如果：你擅长视频、直播、社交媒体
- 不建议如果：传统电商运营
- 预期：费率高，但社交电商机会大

马来西亚 🇲🇾：基础选择
- 建议如果：不知道选哪个，先选这个
- 不建议如果：已经有成熟运营
- 预期：中等水平，稳定可靠

建议方案：
1️⃣ 先选新加坡试水（利润高，好验证商品）
2️⃣ 成功后扩展到泰国、马来
3️⃣ 最后考虑越南、菲律宾走量
```

```
做法：
```

## 高级问题

### Q21：怎么评估一个商品的真实销售潜力？

**A：看这几个指标**

```
指标 1：竞品销量
如果竞品单品月销 > 1000 件 → 市场大
如果竞品单品月销 < 100 件  → 市场小

指标 2：价格稳定性
如果竞品都卖同样价格 → 市场成熟，难赚钱
如果竞品价格差异大  → 市场分化，有机会

指标 3：评价数量
评价多 → 市场接受度高
评价少 → 市场接受度低

指标 4：销售评论
评论都是好评 → 商品好
评论有差评  → 要改进

综合判断：
销量大 + 价格稳 + 好评多 = 好品类，值得做
销量小 + 价格乱 + 评价少 = 差品类，不值得做
```

---

### Q22：如何通过优化定价来提高利润？

**A：三个方向**

```
方向 1：降低成本
- 找更便宜的供应商（省 10-20%）
- 优化包装，减轻重量（省 1-3¥）
- 批量拿货获得折扣（省 5-10%）
效果：直接提高 10-30% 利润

方向 2：精准定价
- 不要乱降价，吸引真正愿意付钱的客户
- 区分不同客群（高端 vs 大众）
- 针对性定价，提高客户满意度
效果：保持销量同时提高单价

方向 3：优化费用
- 减少退货率（从 3% 降到 1%）
- 精准投放广告，降低获客成本
- 优化物流，减少运费（从 15¥ 降到 10¥）
效果：间接提高 5-15% 利润

综合优化能提高 30-50% 利润！
```

---

### Q23：定价后多久要更新一次？

**A：按优先级更新**

```
高优先级（每周检查）：
- 竞品价格（可能突然降价）
- 销量和转化率

中优先级（每月检查）：
- 平台费率（通常不变）
- 物流费用（有变化通知）
- 库存状况

低优先级（每季度检查）：
- 关税政策（通常不变）
- 汇率（长期变化）
- 商品成本（通常相对稳定）

特殊情况（立即更新）：
- 平台突然改费率
- 海关关税调整
- 竞品大幅降价
- 物流出现问题
```

## 其他常见问题

### Q24：退货和售后对定价有什么影响？

**A：直接计入成本**

```
退货率：通常 1-3%
- 假设 100 件卖出，3 件被退回
- 退回的 3 件相当于损失

定价时已经考虑了：
- 假设退货损耗 2%
- 定价已经包含这个成本

要点：
✓ 降低退货率 = 提高利润
✓ 优质描述、图片、物流、售后能降低退货
✓ 如果你的退货率 > 5%，说明有问题
```

---

### Q25：什么时候应该停止卖某个商品？

**A：看这几个信号**

```
停止信号：
🔴 利润率 <5%（持续亏本边缘）
🔴 销量 = 0（3 个月没人买）
🔴 退货率 >10%（产品有问题）
🔴 竞品全部下架（品类不适合）
🔴 成本上升，利润被压到 <5%

继续信号：
🟢 利润率 >15%（可持续）
🟢 销量稳定（可预测）
🟢 退货率 <3%（客户满意）
🟢 有升级优化空间（可改进）

决策：
3 个或以上红信号 → 考虑停止
2 个红信号 + 有解决方案 → 继续优化
全是绿信号 → 加大投入
```
