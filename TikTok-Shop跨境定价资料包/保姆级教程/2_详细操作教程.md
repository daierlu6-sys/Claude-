```
   - 越南 🇻🇳
   - 新加坡 🇸🇬
   - 菲律宾 🇵🇭
```

**截图示意**：
```
选择框：[▼ 选择国家]
        ├─ 马来西亚
        ├─ 泰国
        ├─ 越南  ← 点击选中
        ├─ 新加坡

```

**选择建议**：
```
🟢 推荐新手选：新加坡

   • 利润最高
   • 消费力最强

🟡 平衡选择：泰国、马来西亚
   • 费率适中
```

**选完后会发生什么**：

#### 第 2 步：输入采购成本

**操作**：
```
1. 找到"采购成本"这一行
2. 在对应的输入框输入数字（只输数字，不要输单位）
3. 按 Enter 确认
```

**示例**：
```
商品：棉质 T 恤
查询结果：25¥ 一件
输入：25
（不要输"25¥"）
```

**如何确定采购成本**：

| 渠道 | 怎么查 | 典型价格 |
|------|--------|--------|
| 1688.com | 搜商品名，看最小起订价 | 10-100¥ |
| 供应商报价 | 询问多个供应商 | 各不相同 |
| 工厂采购 | 直接去工厂看 | 通常最便宜 |
| 贸易公司 | 他们代理生产 | 中等价格 |

**常见成本范围**：
```
小配件（充电器）：5-20¥
服装（T恤、衣服）：15-50¥
箱包（包包）：30-100¥
电子产品（手机壳）：10-30¥
家居用品（摆件）：20-80¥
```

**输入技巧**：
```
✓ 输入单件成本（100 件的价格 / 100）
✗ 不要输总成本（100 件的总价）

例：
100 件的总价：2500¥
单件成本：2500 ÷ 100 = 25¥
输入：25
```

---

#### 第 3 步：输入商品重量

**操作**：
```
1. 找到"商品重量"这一行
2. 用电子秤称一下商品（包括包装）
3. 换算成 KG（千克）
4. 输入到模板
```

**重量单位转换**：
```
克 (g) → KG
500g  = 0.5 KG
100g  = 0.1 KG
1000g = 1 KG

记住：÷ 1000 = KG
```

**重量怎么测**：

##### 方法 1：有电子秤
```
1. 把商品放在秤上
2. 读数（克）
3. 除以 1000 得到 KG

例：320g → 0.32 KG → 输入 0.32
```

##### 方法 2：没有电子秤
```
用小数估算：
- 纸巾一包：100g = 0.1 KG
- 500ml 矿泉水：500g = 0.5 KG
- 一个手机：200g = 0.2 KG

类比估算你的商品重量
```

##### 方法 3：问供应商
```
直接找工厂或供应商
他们通常知道产品规格
包括重量、体积等
```

**输入示例**：
```
商品：棉质 T 恤
秤重：320 克
转换：320 ÷ 1000 = 0.32 KG
输入：0.32
```

**重要提示**：
```
⚠️ 一定要称包装后的重量！
不是裸品重量，而是打包后的重量

原因：运输时会有包装，
物流商按包装后的重量计费
```

---

#### 第 4 步：输入国内运费

**操作**：
```
1. 找到"国内运费"这一行
2. 联系快递公司询价
3. 或根据经验填写
4. 输入数字（¥，只输数字）
```

**国内运费怎么算**：

##### 路线 1：从工厂 → 自己的仓库
```
询问：快递费用
例：上海工厂 → 你在深圳
快递费用：5¥ 一件
输入：5
```

##### 路线 2：从工厂 → 集运仓
```
工厂直接发到国际集运仓
集运仓：中国境内的仓库
例：工厂 → 深圳集运仓：3¥
输入：3
```

##### 路线 3：工厂代发
```
工厂直接发国外
不需要你收货
国内运费：0¥
输入：0
```

**询价方法**：
```
1. 打开快递 App（顺丰、申通等）
2. 选择"发件地点" = 工厂地址
3. 选择"目的地" = 你的集运仓
4. 选择"快递方式"
5. 看费用

或直接打电话给快递客服询问
```

**典型运费范围**：
```
同城：2-5¥
省内：3-8¥
跨省：5-15¥
海外仓：10-30¥

取决于：
- 距离远近
- 重量大小
- 快递方式
```

**输入示例**：
```
商品：棉质 T 恤
工厂位置：杭州
你的集运仓：广州
快递报价：4¥ 一件
输入：4
```

## 定价结果解读

### 三个关键数字

#### 数字 1：保本售价（绿色）

**含义**：
```
最低必须定这个价
低于这个价格就会亏本
```

**例子**：
```
保本价 145¥ 

如果定价 140¥ → 亏本
如果定价 145¥ → 刚好平本
如果定价 150¥ → 赚 5¥
```

**怎么用**：
```
✓ 作为价格下限参考
✓ 但通常不能按这个价定
✓ 要加上利润才能定价
```

---

#### 数字 2：建议售价（黄色，★★★最重要）

**含义**：
```
考虑了各项费用和合理利润
推荐按这个价格定价
```

**例子**：
```
建议售价 188¥
= 保本 145¥ 
+ 适度利润 43¥
= 合理的定价
```

**怎么用**：
```
1️⃣ 记下这个价格
2️⃣ 去 TikTok 查竞品价格
3️⃣ 对标竞品，微调上下
4️⃣ 最终定价通常在：
   建议价 -10% 到 +10% 之间
```

**调整范围**：
```
建议价 188¥

能定价的范围：169-207¥
│
├─ 169¥（-10%）：比较便宜，容易卖
├─ 188¥（正常）：建议价格
└─ 207¥（+10%）：比较贵，高质高价

不建议超出这个范围太多
```

---

#### 数字 3：单店利润和利润率

**单店利润** = 一件产品赚多少钱

```
例：70¥

卖 1 件 → 赚 70¥
卖 10 件 → 赚 700¥
卖 100 件 → 赚 7000¥
```

**利润率** = 利润 / 定价

```
例：37%

定价 188¥ 中，有 37% 是纯利
剩下 63% 用来支付各项成本
```

**判断标准**：

| 利润率 | 评价 | 建议 |
|--------|------|------|
| <5% | 🔴 太低 | 别卖，亏本边缘 |
| 5-10% | 🟡 一般 | 可以但要走量 |
| 10-20% | 🟡 还好 | 还可以，持续卖 |
| 20-40% | 🟢 很好 | 优秀品类，加大投入 |
| 40%+ | 🟢 优秀 | 爆款，尽快铺货 |

## 常见操作问题

### 问 1：我想定价 100¥，模板怎么用？

**场景**：
```
你知道想定价 100¥
想反推需要多少成本

做法：
1. 在"采购成本"输入框试不同数字
2. 观察"建议售价"变化
3. 调整到接近 100¥ 为止

例如：
输入成本 30¥ → 建议价 100¥ ✓
这样你就知道需要 30¥ 的成本
```

---

### 问 2：同一商品在不同国家定价差很多，我怎么选？

**场景**：
```
同一商品（T 恤）

新加坡：180 SGD（约 1080¥）利润 45%
泰国：900 THB（约 180¥）利润 35%
越南：500,000 VND（约 120¥）利润 18%

怎么选？
```

**分析**：
```
选项 A：只卖新加坡
- 利润最高
- 但市场小，销量可能少

选项 B：只卖泰国或马来
- 利润中等，市场中等
- 平衡之选

选项 C：分散销售
- 新加坡卖高端客户
- 越南卖大众客户
- 降低风险

建议：先卖新加坡试水，再扩展
```

---

### 问 3：我要卖多个 SKU，怎么管理？

**方案 A：同一张表，多行**
```
行 1：T 恤 - 结果
行 2：衬衣 - 结果
行 3：外套 - 结果
...

优点：一张表看全部
缺点：看起来有点乱
```

**方案 B：多个 Sheet，每个品类一个**
```
Sheet1：T 恤
Sheet2：衬衣
Sheet3：外套
...

优点：清晰明了
缺点：要切换 Sheet
```

**建议**：
```
少于 5 种：用方案 A
5 种以上：用方案 B
```

### 问 4：模板显示的是哪种货币？

**规律**：
```
采购成本：输入 ¥（人民币）

其他费用：用该国货币
- 马来：MYR
- 泰国：THB
- 越南：VND
- 新加坡：SGD
- 菲律宾：PHP

建议：
在结果旁边标注货币符号
避免混淆
```
