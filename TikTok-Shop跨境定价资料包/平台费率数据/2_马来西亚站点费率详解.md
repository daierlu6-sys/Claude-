## 核心费率详解

### 1. 平台佣金

**费率**：5%  
**计费方式**：按订单商品售价计算  
**实际案例**：

```
商品售价：100 MYR
平台佣金：100 × 5% = 5 MYR ≈ 7.5-8¥

商品售价：500 MYR
平台佣金：500 × 5% = 25 MYR ≈ 37.5-40¥
```

**优惠条件**：
- 新卖家开业期间：可能降至 3% 或 4%
- 平台重点扶持品类：3-4%
- 政府活动期间：可能阶段性优惠

---

### 2. 交易手续费

**费率**：2%  
**计费方式**：按订单商品售价计算  
**支付方式细分**：

| 支付方式 | 手续费率 | 说明 |
|--------|--------|------|
| 信用卡 | 2.0% | Visa、MasterCard等 |
| 电子钱包 | 1.8% | GCash、PayMaya等 |
| 银行转账 | 1.5% | 直接银行支付 |
| 分期付款 | 2.5% | 金融科技分期 |

**计算示例**：

```
订单金额：100 MYR
交易手续费：100 × 2% = 2 MYR ≈ 3¥
```

---

### 3. 增值税（SST）

**税率**：6%（可退回）  
**覆盖范围**：大部分商品  
**豁免品类**：

- ✅ 食品类（基本生活用品）
- ✅ 书籍、报刊
- ✅ 残疾人用具
- ✅ 医疗用品（部分）
- ✅ 儿童用品（部分）

**计税基数**：
```
SST基数 = 商品售价 + 邮费
SST = (商品售价 + 邮费) × 6%
```

**重点说明**：
- 中国卖家需向马来海关申报增值税编号
- 部分品类可申请豁免
- 购买者有时会承担部分税费

---

### 4. 关税

**按品类不同**：

| 商品类别 | 关税率 | 说明 | 常见品 |
|--------|--------|------|--------|
| 服装/鞋 | 15-25% | 按编码不同 | T恤、鞋、袜子 |
| 纺织品 | 10-20% | 面料类 | 布料、手帕 |
| 电子产品 | 5-15% | 手机配件较高 | 充电器、数据线 |
| 皮革制品 | 20-25% | 箱包、钱包 | 手提包、皮带 |
| 化妆品 | 10-15% | 护肤品较低 | 面膜、护肤液 |
| 珠宝 | 5-10% | 金饰较低 | 戒指、项链 |
| 户外用品 | 10-20% | 运动装备 | 登山包、帐篷 |
| 家居用品 | 10-20% | 装饰品较高 | 台灯、抱枕 |

**关税计算**：

```
CIF值 = 成本 + 国际运费 + 保险费
关税 = CIF值 × 关税率

示例：
成本：300¥
运费：50¥
保险：10¥
CIF = 360¥
关税率：15%
应付关税 = 360 × 15% = 54¥
```

- 国内运费：2¥
- 重量：0.3KG

- 物流方式：专线
- 关税率：15%（服装）
- 广告预算：20%

**费用明细**：

| 费用项 | 计算 | 金额 |
|-------|-----|------|
| 采购成本 | 直接 | 25¥ |
| 国内运费 | 直接 | 2¥ |
| 跨境物流 | 10¥ | 10¥ |
| 货代费 | 采购×5% | 1.5¥ |
| 关税 | (25+2+10)×15% | 5.25¥ |
| 平台佣金 | 240×5% | 12¥ |
| 交易手续费 | 240×2% | 4.8¥ |
| 增值税（自承） | 240×3% | 7.2¥ |
| 广告费 | 240×20% | 48¥ |
| 退货损耗 | 240×2% | 4.8¥ |
| **总成本** | **汇总** | **120.55¥** |

**定价分析**：
```
销售价：240¥
总成本：120.55¥
毛利：240 - 120.55 = 119.45¥
利润率：119.45 / 240 = 49.8%
```

**结论**：该产品在马来西亚定价250¥，利润率约50%，属于优质产品
