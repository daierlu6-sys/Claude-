## 物流成本优化技巧

### 1️⃣ 选择合适的物流渠道

**原则**：
```
时间充裕（15天+）→ 邮政小包（最便宜）
时间紧张（3-7天）→ 专线物流（最平衡）
客户催促（1-3天）→ 快递（时效但贵）
```

### 2️⃣ 合理分割重量

**案例**：3.5KG 商品

```
方案 A：一起发（3.5KG）
专线：10 + 2.5×4 = 20¥

方案 B：分两单发（1.5KG + 2KG）
专线：10 + 10 = 20¥（一样）

方案 C：发两个轻件（1.8KG + 1.7KG）
邮政：15 + 15 = 30¥（更贵）

结论：通常一起发最优
```

### 3️⃣ 利用返回运费

有些物流商提供返回单优惠
- 发出单：标准价
- 返回单：优惠 20-30%
- 适合：双向贸易（有货源地返回）

### 4️⃣ 与物流商协议

**大批量发货**可以协议：
- 月度 50+ 单：可协议 5-10% 优惠
- 月度 100+ 单：可协议 10-15% 优惠
- 稳定客户：长期优惠

**示例**：
```
原价 20¥ × 10% 优惠 = 18¥
省 2¥，100 单省 200¥
```

## 快速选择指南

### 根据商品选择物流

**小型电子产品（手机壳、充电器）**
```
重量：0.1-0.5KG
推荐：专线物流
理由：时效快（4-6天），成本低（8-14¥）
```

**服装/鞋类（T恤、裤子）**
```
重量：0.3-0.8KG
推荐：邮政小包（时间充裕）或专线（时间紧）
理由：邮政便宜（12-20¥），专线快（8-14¥）
```

**箱包（包包、行李箱）**
```
重量：0.5-2KG
推荐：专线物流
理由：重量不算重，时效需求中等
费用：14-20¥
```

**家居用品（灯具、摆件）**
```
重量：1-3KG
推荐：邮政小包（便宜）或海派（超低价）
理由：时间可以等待
费用：邮政 15-25¥，海派 5-10¥
```
