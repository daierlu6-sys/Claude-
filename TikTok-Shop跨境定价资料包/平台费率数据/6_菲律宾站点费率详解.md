## 核心费率详解

### 1. 平台佣金

**费率**：6%（东南亚最高）  
**计费基数**：商品售价  
**说明**：

```
商品售价：500 PHP (约65¥)
佣金：500 × 6% = 30 PHP ≈ 3.9¥

菲律宾佣金率比其他国家高 1%
```

**费率特点**：
- 菲律宾是唯一 6% 佣金的国家
- 新卖家无特殊优惠（直接 6%）
- 没有阶梯式降费
- 无法协商

---

### 2. 交易手续费

**费率**：2.5%（东南亚最高）  
**计费基数**：订单金额  
**支付方式细分**：

| 支付方式 | 手续费率 | 流行度 |
|--------|--------|-------|
| GCash | 2.5% | ⭐⭐⭐⭐⭐（最流行） |
| PayMaya | 2.5% | ⭐⭐⭐⭐（常用） |
| BDO | 2.0% | ⭐⭐⭐（银行） |
| 信用卡 | 3.0% | ⭐⭐（国际卡） |

**计算示例**：

```
订单金额：500 PHP
手续费：500 × 2.5% = 12.5 PHP ≈ 1.62¥
```

---

### 3. 增值税（VAT）

**税率**：12%（东南亚最高）  
**覆盖范围**：几乎所有商品  
**豁免极少**：

- ✅ 基本生活食品
- ✅ 医疗用品
- ✅ 教科书

**计税方式**：
```
VAT = 商品售价 × 12%
```

**特别说明**：
- 菲律宾 VAT 是 5 国中最高的
- 直接增加成本 12%
- 新卖家无豁免机制

---

### 4. 关税

**关税率范围**：0-15%（相对中等）

| 商品类别 | 关税率 | 典型品类 |
|--------|--------|--------|
| 电子产品 | 5-10% | 配件、手机壳 |
| 服装/鞋 | 10-15% | T恤、运动鞋 |
| 美妆护肤 | 10-15% | 面膜、护肤液 |
| 箱包配饰 | 10-15% | 包包、皮带 |
| 家居用品 | 10-15% | 装饰品、摆件 |
| 食品 | 0-15% | 干货、零食 |
| 珠宝/饰品 | 10-15% | 项链、戒指 |

**关税计算**：

```
CIF = 成本 + 国际运费 + 保险
关税 = CIF × 关税率

示例（T恤）：
成本：20¥
运费：8¥
保险：1¥
CIF：29¥
关税率：12%
应付关税：29 × 12% = 3.48¥
```

## 完整费率计算案例

### 案例：销售手机壳

**基本信息**：
- 采购成本：12¥
- 国内运费：1¥
- 重量：0.2KG
- 销售价：300 PHP（约39¥）
- 物流方式：邮政小包
- 关税率：8%
- 广告投入：12%

**费用明细**：

| 费用项 | 计算 | 金额 |
|-------|-----|------|
| 采购成本 | 直接 | 12¥ |
| 国内运费 | 直接 | 1¥ |
| 跨境物流 | 邮政首重 | 18¥ |
| 货代费 | 采购×5% | 0.6¥ |
| 关税 | (12+1+18)×8% | 2.48¥ |
| 平台佣金 | 39×6% | 2.34¥ |
| 交易手续费 | 39×2.5% | 0.98¥ |
| VAT（自承） | 39×7% | 2.73¥ |
| 广告费 | 39×12% | 4.68¥ |
| 退货损耗 | 39×2% | 0.78¥ |
| **总成本** | **汇总** | **46.6¥** |

**定价分析**：
```
销售价：39¥
总成本：46.6¥
亏损：-7.6¥
```

**问题**：定价太低！商品亏损

**优化方案**：
```
调整定价至 600 PHP (约78¥)：
总费用不变约 46.6¥
利润：78 - 46.6 = 31.4¥
利润率：40%
```

**结论**：菲律宾费率高，需要定价高才能盈利
