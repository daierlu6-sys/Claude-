## 核心费率详解

### 1. 平台佣金

**费率**：5%  
**计费基数**：商品售价  
**特殊说明**：

```
商品售价：50 SGD (约300¥)
佣金：50 × 5% = 2.5 SGD ≈ 15¥

新加坡消费力强，客单价通常较高
```

**优惠条件**：
- 新卖家首月：3-4% 佣金
- 重点扶持品类：可协商至 4%
- 超级卖家：可享受 4-4.5% 佣金

---

### 2. 交易手续费

**费率**：2%  
**计费基数**：订单金额  
**支付方式细分**：

| 支付方式 | 手续费率 | 特点 |
|--------|--------|------|
| PayLah | 2.0% | 本地电子钱包 |
| GCash | 2.0% | 跨地区通用 |
| 信用卡 | 2.0% | 国际卡普遍接受 |
| Apple Pay | 2.0% | 高消费力人群 |
| 银行转账 | 1.5% | 最便宜但使用少 |

**计算示例**：

```
订单金额：50 SGD
手续费：50 × 2% = 1 SGD ≈ 6¥
```

---

### 3. 增值税（GST）

**税率**：8%（出口可豁免）  
**覆盖品类**：大部分进口商品  
**豁免品类**：

- ✅ 出口商品（中国卖家通常豁免）
- ✅ 食品（大部分基本食品）
- ✅ 医疗用品
- ✅ 儿童用品（部分）

**计税方式**：
```
通常出口商品豁免GST
需要提供出口证明
```

**特别说明**：
- 新加坡对中国卖家最友好
- 出口通常可以豁免
- 需要相关申报文件

---

### 4. 关税

**关税率范围**：0-5%（**全东南亚最低**）

| 商品类别 | 关税率 | 典型品类 |
|--------|--------|--------|
| 电子产品 | 0% | 充电器、配件 |
| 服装/鞋 | 0-5% | 大部分豁免 |
| 美妆护肤 | 5% | 部分护肤品 |
| 箱包配饰 | 0-3% | 大部分豁免 |
| 家居用品 | 0-3% | 装饰品豁免 |
| 食品 | 0% | 基本豁免 |
| 珠宝/饰品 | 0% | 基本豁免 |

**关税计算**：

```
由于新加坡大部分商品关税为0%
实际计算：
CIF = 成本 + 运费 + 保险
关税 = CIF × 关税率（通常为0%）
```

**极大优势**：
- 新加坡关税最低可以忽略
- 这是与其他国家最大的竞争优势
- 同样成本，新加坡可以定价更低

| 费用项 | 计算 | 金额 |
|-------|-----|------|

| 退货损耗 | 480×2% | 9.6¥ |

**定价分析**：
```
销售价：480¥
```

3. **利润优先**：不用追求销量，追求单店利润
