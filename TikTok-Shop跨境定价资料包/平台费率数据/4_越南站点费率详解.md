## 核心费率详解

### 1. 平台佣金

**费率**：5%  
**计费基数**：商品售价  
**注意事项**：

```
商品售价：500,000 VND (约120¥)
佣金：500,000 × 5% = 25,000 VND ≈ 6¥

注：佣金为平台默认费率，新卖家可能享受优惠
```

**新卖家优惠**：
- 开业前3个月：3% 佣金
- 月度精品活动：3.5-4%
- 特殊品类扶持：可降至 3%

---

### 2. 交易手续费

**费率**：2%  
**计费基数**：商品售价  
**支付方式差异**：

| 支付方式 | 手续费率 | 流行度 |
|--------|--------|-------|
| ZaloPay | 2.0% | ⭐⭐⭐⭐⭐（最流行） |
| Momo | 2.0% | ⭐⭐⭐⭐⭐（常用） |
| VCB | 1.5% | ⭐⭐⭐（银行直接） |
| 信用卡 | 2.5% | ⭐⭐（国际卡） |

**计算示例**：

```
订单金额：500,000 VND
手续费：500,000 × 2% = 10,000 VND ≈ 2.4¥
```

---

### 3. 增值税（VAT）

**税率**：10%（较高）  
**覆盖范围**：几乎所有商品  
**豁免极少**：

- ✅ 基本农产品
- ✅ 医疗用品（部分）
- ✅ 教科书

**计税方式**：
```
VAT = 商品售价 × 10%
（一般运费不计）
```

**特别说明**：
- 越南增值税为东南亚最高
- 直接影响成本
- 无法豁免（除非特殊品类）

---

### 4. 关税

**关税率范围**：0-25%（相对较高）

| 商品类别 | 关税率 | 典型品类 | 说明 |
|--------|--------|--------|------|
| 电子产品 | 5-15% | 手机配件 | 整机征税高 |
| 服装/鞋 | 15-25% | T恤、运动鞋 | 较高 |
| 美妆护肤 | 10-25% | 面膜、护肤 | 按成分差异大 |
| 箱包配饰 | 20-25% | 包包、皮带 | 税率较高 |
| 家居用品 | 15-25% | 装饰品 | 按材质不同 |
| 食品 | 0-25% | 干货、零食 | 差异最大 |
| 珠宝/饰品 | 5-15% | 项链、戒指 | 贵金属较低 |

**关税计算**：

```
CIF = 产品成本 + 国际运费 + 保险
关税 = CIF × 关税率

示例（T恤）：
成本：20¥
国际运费：8¥
保险：1¥
CIF：29¥
关税率：20%
应付关税：29 × 20% = 5.8¥
```

**重要提示**：
- 越南海关查验较严
- 申报价值过低可能被驳回
- 同一品类不同海关可能有差异

- 广告投入：10%

**费用明细**：

| 费用项 | 计算 | 金额 |
|-------|-----|------|
| 采购成本 | 直接 | 18¥ |

| 跨境物流 | 邮政首重 | 20¥ |
| 货代费 | 采购×5% | 0.9¥ |

**定价分析**：
```
销售价：72¥

```

**问题**：利润过低！需要调整定价策略

**优化方案**：

## 销售建议

### ✅ 优势品类
- **平价时尚服装**（市场规模大，竞争激烈但机会大）
- **电子配件**（消费频次高）
- **快消品**（购买频率高）
- **轻量商品**（控制物流成本）

### ⚠️ 谨慎销售
- 高价商品（低消费力）
- 重型产品（物流成本高，利润被侵蚀）
- 食品类（关税和税务复杂）

### 💡 定价策略
1. **价格敏感市场**：定价需要控制在成本的 2-3 倍
2. **春节提价**：1月可提价20-30%（需提前备货）
3. **常规期**：对标竞品，走薄利多销
4. **淡季促销**：可做 15-20% 折扣激活销量

## 越南特有机会

### 💡 赚钱机会
1. **春节效应**：1月销量和价格都能上升，是全年最好的赚钱期
2. **市场增长**：电商渗透率还在上升，增长空间大
3. **竞争少**：相比马来、泰国竞争压力较小
4. **消费升级**：年轻消费者愿意买更好的商品

1. **关税较高**：需要仔细计算
2. **增值税最高**：10%的成本压力
3. **物流较长**：预计7-15天
4. **消费力有限**：定价空间受限
