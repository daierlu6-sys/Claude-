## 核心费率详解

### 1. 平台佣金

**费率**：5%  
**计费方式**：按订单售价计算  
**特殊规定**：

```
商品售价：500 THB (约100-110¥)
佣金：500 × 5% = 25 THB ≈ 5.5¥

不同品类可能有小额调整（±0.5%）
```

**免佣金品类**：无（所有品类均收佣）

**优惠活动**：
- 新卖家前3个月可享受 3% 佣金
- 平台月度精品活动参与者：3.5-4%
- 超级卖家等级可协商费率

---

### 2. 交易手续费

**费率**：2%  
**计费基数**：订单商品售价 + 邮费  
**支付方式细分**：

| 支付方式 | 手续费率 | 备注 |
|--------|--------|------|
| Promptay | 2.0% | 泰国最流行 |
| TrueMoney | 2.0% | 电子钱包 |
| LINE Pay | 2.0% | 即时通讯支付 |
| 信用卡 | 2.5% | 国际卡费率略高 |
| 银行转账 | 1.5% | 最便宜 |

**计算示例**：

```
订单金额：500 THB
邮费：50 THB
手续费基数：550 THB
手续费：550 × 2% = 11 THB ≈ 2.2¥
```

---

### 3. 增值税（VAT）

**税率**：7%（部分出口可豁免）  
**覆盖品类**：大部分商品  
**豁免品类**：

- ✅ 出口食品（新鲜农产品）
- ✅ 出口服务
- ✅ 国际运输服务
- ✅ 医疗服务

**计税方式**：
```
增值税 = 商品售价 × 7%
（运费一般不计税）
```

**特别说明**：
- 中国卖家多数商品按出口处理，可能豁免增值税
- 需提供相关证明文件
- 建议咨询平台官方

---

### 4. 关税

**关税率范围**：0-20%（相对较低）

| 商品类别 | 关税率 | 典型品类 |
|--------|--------|--------|
| 电子产品 | 5-10% | 手机配件、充电器 |
| 服装/鞋 | 10-20% | T恤、运动鞋 |
| 美妆护肤 | 10-15% | 面膜、护肤液 |
| 箱包配饰 | 15-20% | 包包、皮带 |
| 家居用品 | 10-15% | 摆件、台灯 |
| 食品 | 0-15% | 干货、零食 |
| 珠宝/饰品 | 5-10% | 项链、戒指 |

**关税计算**：

```
CIF = 成本 + 国际运费 + 保险
关税 = CIF × 关税率

示例（T恤）：
成本：20¥
运费：8¥
保险：1¥
CIF：29¥
关税率：15%
应付关税：29 × 15% = 4.35¥
```

## 完整费率计算案例

### 案例：销售连衣裙

**基本信息**：
- 采购成本：35¥
- 国内运费：2¥
- 重量：0.4KG
- 销售价：800 THB（约160-180¥）
- 物流方式：专线
- 关税率：20%
- 广告投入：15%

**费用明细**：

| 费用项 | 计算 | 金额 |
|-------|-----|------|
| 采购成本 | 直接 | 35¥ |
| 国内运费 | 直接 | 2¥ |
| 跨境物流 | 专线首重 | 12¥ |
| 货代费 | 采购×5% | 1.75¥ |
| 关税 | (35+2+12)×20% | 9.8¥ |
| 平台佣金 | 170×5% | 8.5¥ |
| 交易手续费 | 170×2% | 3.4¥ |
| VAT（自承） | 170×4% | 6.8¥ |
| 广告费 | 170×15% | 25.5¥ |
| 退货损耗 | 170×2% | 3.4¥ |
| **总成本** | **汇总** | **108.75¥** |

**定价分析**：
```
销售价：170¥
总成本：108.75¥
毛利：61.25¥
利润率：36%
```

**建议**：该产品可定价180-200¥，利润率在30-37%之间，属于良好产品

## 销售建议

### ✅ 优势品类
- 女性时尚服装（市场需求大）
- 美妆护肤（消费频次高，利润好）
- 轻量电子配件（物流成本低）
- 饰品/配件（关税低，利润高）

### ⚠️ 谨慎销售
- 重型产品（物流成本高）
- 低价快消品（利润空间小）
- 食品类（税务复杂）

### 💡 定价策略
1. **新品/差异化品**：定价较高（3-5倍成本）
2. **竞争品类**：对标竞品，略微优惠5-10%
3. **季节品**：高峰期保持价格，淡季可促销10-20%
