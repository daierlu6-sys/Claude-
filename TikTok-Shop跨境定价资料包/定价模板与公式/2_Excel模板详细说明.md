## 第一块：参数输入区

### 位置：A1-E10

#### A1：站点选择
```
单元格：A1
类型：下拉菜单
选项：
- 马来西亚
- 泰国
- 越南
- 新加坡
- 菲律宾

功能：决定所有费率
```

**公式逻辑**：
```
IF(站点="马来西亚", 费率1, IF(站点="泰国", 费率2, ...))
```

#### B1-B3：关键输入

| 单元格 | 输入项 | 单位 | 示例 |
|--------|--------|------|------|
| B1 | 采购成本 | ¥ | 50 |
| B2 | 商品重量 | KG | 0.5 |
| B3 | 国内运费 | ¥ | 5 |

**验证**：
- B1：数字、>0、<1000
- B2：小数、>0、<50
- B3：数字、>0、<100

## 第二块：费用计算区

### 位置：A12-B25

#### 费用项 1-10：计算公式

##### 公式 1：拿货成本
```
= B1
直接引用采购成本
```

##### 公式 2：国内运费
```
= B3
直接引用国内运费
```

##### 公式 3：货代费
```
= B1 * 5%
采购成本的 5%
```

##### 公式 4：跨境物流费（**复杂**）
```
=VLOOKUP(B2, 物流表, 相应列)

其中物流表包括：
重量  | 马来  | 泰国  | 越南  | 新加坡 | 菲律宾
0-1   | 10    | 12    | 14    | 8      | 14
1-2   | 14    | 17    | 20    | 11     | 20
2-5   | 26    | 32    | 38    | 20     | 38
5-10  | 46    | 52    | 54    | 44     | 54

根据重量和国家查询相应物流费
```

**简化公式**（如果不用 VLOOKUP）：
```
IF(A1="马来西亚",
  IF(B2<=1, 10, IF(B2<=2, 14, IF(B2<=5, 26, 46))),
  IF(A1="泰国",
    IF(B2<=1, 12, IF(B2<=2, 17, IF(B2<=5, 32, 52))),
    ...
  )
)
```

##### 公式 5：关税
```
= (B1 + B3 + 物流费) * 关税率

其中关税率根据国家和品类：
马来：15% (可改)
泰国：15% (可改)
越南：20% (可改)
新加坡：0% (不改)
菲律宾：12% (可改)
```

**实际公式**：
```
= (B1 + B3 + 物流费) * VLOOKUP(A1, 关税表, 2)
```

##### 公式 6：小计（直接成本）
```
= 拿货 + 国内运 + 货代 + 跨境运 + 关税

例：
= B12 + B13 + B14 + B15 + B16
```

#### 费用项 7-10：基于定价的费用

**关键点**：这些费用是根据**最终售价**计算的，但我们还没有最终售价，所以这里需要用"迭代"或"最终定价回代"

##### 方案 A：迭代计算（自动）

```
定义：以最终售价为基准，反推所有百分比费用

公式（以平台佣金为例）：
= 最终售价 * 5%

但最终售价 = 成本 + 佣金 + 手续费 + ...
这是循环引用！

解决方案：使用迭代公式或分开计算
```

##### 方案 B：分步计算（推荐）

###### 第 1 步：计算"直接成本小计"
```
直接成本 = 拿货 + 国内运 + 货代 + 跨境运 + 关税
```

###### 第 2 步：计算"平台和财务费用比例"
```
平台费率总和 = 佣金率 + 手续费率 + VAT 率

例：马来西亚
= 5% + 2% + 6% = 13%
```

###### 第 3 步：计算保本售价
```
保本售价 = 直接成本 / (1 - 平台费率总和 - 广告比例 - 退货率)

以马来为例：
= 直接成本 / (1 - 0.13 - 0.20 - 0.02)
= 直接成本 / 0.65
```

###### 第 4 步：基于保本价计算各项费用
```
平台佣金 = 保本售价 * 5%
交易手续费 = 保本售价 * 2%
增值税 = 保本售价 * 6%
```

| 费用项 | 公式 | 例值 |
|--------|------|------|
| 拿货成本 | = B1 | 50¥ |
| 国内运费 | = B3 | 5¥ |
| 货代费 | = B1*5% | 2.5¥ |
| 跨境物流 | = VLOOKUP(B2, 物流表, 国家列) | 10¥ |

| 平台佣金 | = 保本售价 * 5% | 6.63¥ |
| 交易手续费 | = 保本售价 * 2% | 2.65¥ |
| 增值税 | = 保本售价 * 6% | 7.96¥ |
| 广告费 | = 保本售价 * 20% | 26.52¥ |
| 退货损耗 | = 保本售价 * 2% | 2.65¥ |

## 第三块：定价输出区

### 位置：A30-B40

#### 输出 1：保本售价
```
公式：= 直接成本 / (1 - 平台费率 - 广告比例 - 退货率)

含义：最低必须定这个价，否则亏损

示例：
= 77.85 / (1 - 0.13 - 0.20 - 0.02)
= 77.85 / 0.65
= 119.77¥ ≈ 120¥
```

#### 输出 2：建议售价
```
公式：= 保本售价 * (1 + 目标利润率)

含义：考虑合理利润的建议定价

利润率选择：
- 新品/差异化：30-50%
- 常规竞争：20-30%
- 走量/爆款：10-20%

示例（利润率 30%）：
= 120 * 1.3 = 156¥
```

#### 输出 3：单店利润
```
公式：= 建议售价 - 直接成本 - (建议售价 * 平台费率)

含义：一件产品实际赚多少钱

示例：
= 156 - 77.85 - (156 * 0.13)
= 156 - 77.85 - 20.28
= 57.87¥
```

#### 输出 4：利润率
```
公式：= 单店利润 / 建议售价

含义：利润 / 定价，百分比

示例：
= 57.87 / 156 = 37%
```

## 国家切换时的费率变化

### 自动转换表

```
当 A1 选择不同国家时，以下参数自动改变：

参数         | 马来  | 泰国  | 越南  | 新加坡 | 菲律宾
佣金率       | 5%    | 5%    | 5%    | 5%     | 6%
手续费       | 2%    | 2%    | 2%    | 2%     | 2.5%
VAT/GST      | 6%    | 7%    | 10%   | 8%*    | 12%
关税率基值   | 15%   | 15%   | 20%   | 0%     | 12%
物流费表     | 表M   | 表T   | 表V   | 表S    | 表P

* 新加坡出口通常豁免 GST
```

### 实现方式

使用 **IF 嵌套** 或 **VLOOKUP 查询表**：

```excel
=IF(A1="马来西亚", 5%, IF(A1="泰国", 5%, IF(A1="越南", 5%, IF(A1="新加坡", 5%, 6%))))

或

=VLOOKUP(A1, 费率查询表, 佣金列)
```

## 特殊功能说明

### 功能 1：动态物流费计算

**原理**：根据重量区间查询对应费用

```excel
位置：B15（物流费）

公式：
=IF(B2<=1, 
    VLOOKUP(A1, 物流表, 2), 
    IF(B2<=2, 
        VLOOKUP(A1, 物流表, 3),
        IF(B2<=5,
            VLOOKUP(A1, 物流表, 4),
            VLOOKUP(A1, 物流表, 5)
        )
    )
)

或使用条件公式：
=INDEX(物流表, MATCH(A1, 国家列), MATCH(ROUNDUP(B2,0), 重量列))
```

---

### 功能 2：关税自动调整

**原理**：关税率可根据品类手动改，但默认值按国家

```excel
位置：B16（关税）

默认关税率：
=IF(A1="马来西亚", 15%, IF(A1="泰国", 15%, ...))

但可用单独单元格（如 D1）输入实际关税率
公式改为：
= (B1 + B3 + B15) * D1
```

---

### 功能 3：广告比例调整

**原理**：可按店铺阶段调整

```excel
位置：假设 C25（广告费）

新店铺（0-3月）：15-20%
成长店铺（3-12月）：10-15%
成熟店铺（12月+）：5-10%

公式：
= 建议售价 * (店铺等级所对应的广告比例)

可用下拉菜单选择：
=IF(广告比例="新店", 20%, IF(广告比例="成熟", 8%, 12%))
```

---

### 功能 4：利润率反推定价

**场景**：我想定价 100¥，利润率能有多少？

```excel
反向计算：

给定：建议售价 = 100¥
求：利润率 = ?

利润率 = (100 - 所有成本) / 100

所有成本 = 直接成本 + (100 * 平台费率)
```

## 常用公式库

### 公式 1：成本合计
```
=SUM(B12:B16)
```

### 公式 2：平台费用合计
```
=SUM(B18:B21)
```

### 公式 3：总成本（含平台费）
```
=B12:B16之和 + (建议售价 * 平台费率)
```

### 公式 4：利润（绝对值）
```
=建议售价 - 总成本
```

### 公式 5：利润率（相对值）
```
=利润 / 建议售价
```

### 公式 6：多店铺对比利润
```
=建议售价 * (1 - 平台费率 - 直接成本/建议售价)
```

## 数据验证和错误检查

### 可能的错误

| 错误 | 原因 | 解决 |
|------|------|------|
| #VALUE! | 输入了文本而非数字 | 检查 B1-B3 是否为数字 |
| #REF! | 公式引用了删除的单元格 | 重新输入公式 |
| #DIV/0! | 除以零 | 检查分母是否为 0 |
| 利润为负 | 成本太高或定价太低 | 降低成本或提高定价 |

国内运费：0-100¥
广告比例：0%-50%

## 模板修改和扩展

### 修改场景 1：添加新品类

```
原：关税率固定 15%
改：按品类查询不同关税率

做法：
1. 在 A4 添加"品类"下拉菜单
2. 在关税公式中使用 VLOOKUP 查询

=VLOOKUP(A4, 品类关税表, 2)
```

### 修改场景 2：添加多店铺对比

```
原：只计算一个店铺
改：同时计算 5 个国家

做法：
创建 5 个并行计算区域
或创建 5 个 Sheet，分别对应各国
```

### 修改场景 3：添加销量和月利润预测

```
公式：
月利润 = 单品利润 * 预计月销量

例：
月销 50 件
单品利润 50¥
月利润 = 50 * 50 = 2500¥
```
