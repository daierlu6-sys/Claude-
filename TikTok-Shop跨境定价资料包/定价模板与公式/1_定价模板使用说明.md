# 📊 定价模板使用说明

## 快速开始（3分钟上手）

### 第一步：打开模板
下载 `TikTok-Shop自动定价模板.xlsx` 文件

### 第二步：选择国家
在顶部的"站点选择"下拉菜单，选择你要销售的国家：
- 🇲🇾 马来西亚
- 🇹🇭 泰国
- 🇻🇳 越南
- 🇸🇬 新加坡
- 🇵🇭 菲律宾

### 第三步：输入三个关键数据

| 输入项 | 说明 | 示例 |
|--------|------|------|
| **采购成本** | 从供应商拿货的价格（¥） | 50 |
| **商品重量** | 产品实际重量（KG） | 0.5 |
| **国内运费** | 国内快递到集运点费用（¥） | 5 |

### 第四步：查看结果

模板自动计算：
- ✅ 保本售价（必须高于这个价）
- ✅ 建议售价（推荐定价）
- ✅ 单店利润（一件赚多少钱）
- ✅ 利润率（利润 / 售价）

## 输入参数详细说明

### 1. 采购成本（¥）

**定义**：从供应商购入商品的价格

**如何确定**：
```
去阿里巴巴、1688 查询
填入的是单件成本价
```

**示例**：
```
T恤采购成本：25¥
充电器采购成本：18¥
包包采购成本：80¥
```

**注意**：
- ⚠️ 包含生产成本和供应商利润
- ⚠️ 不包含国内运费（单独输入）
- ✅ 填入人民币金额

---

### 2. 商品重量（KG）

**定义**：产品实际重量（含包装）

**如何确定**：
- 用电子秤称重
- 或查看商品规格表
- 或向供应商询问

**示例**：
```
T恤重量：0.3KG
充电器重量：0.15KG
包包重量：1.2KG
```

**重要**：
- 📌 重量决定物流费用
- 📌 直接影响成本和定价
- 📌 务必准确称量

**优化建议**：
```
如果能减轻 0.2KG，运费可省 1-2¥
建议与工厂沟通优化包装
```

---

### 3. 国内运费（¥）

**定义**：商品从工厂/仓库到集运仓或出口港口的运费

**如何确定**：
- 询问快递公司（顺丰、申通等）
- 或向供应商咨询
- 或查询快递单价

**示例**：
```
华南→广州集运：3¥
华东→上海港：5¥
华北→北京仓：8¥
```

**典型费用**：
```
轻件（<1KG）：2-5¥
中件（1-5KG）：5-15¥
重件（5KG+）：15-30¥+
```

**优化建议**：
```
- 与物流商签年度协议，可降 10-20%
- 集中发货，享受体积优惠
- 选择专线物流比快递便宜 30-50%
```

## 成本分解项详解

模板会自动计算以下成本项：

### 1️⃣ 拿货成本
```
= 采购成本
最基础的成本
```

### 2️⃣ 国内运费
```
= 你输入的国内运费
```

### 3️⃣ 货代费
```
= 采购成本 × 5%
找货代帮你处理报关、打包等
通常是采购价的 5%
```

### 4️⃣ 跨境物流费
```
= 根据国家和重量自动计算
使用本资料包提供的物流费率表
```

### 5️⃣ 关税
```
= (拿货成本 + 国内运费 + 跨境物流) × 关税率
关税率由国家和品类决定
```

### 6️⃣ 平台佣金
```
= 建议售价 × 平台佣金率
例：马来西亚 5%
```

### 7️⃣ 交易手续费
```
= 建议售价 × 手续费率
例：马来西亚 2%
```

### 8️⃣ 增值税（自承）
```
= 建议售价 × 增值税率
部分品类可能豁免，但保守按满征
```

### 9️⃣ 广告投入
```
= 建议售价 × 广告比例
新店铺建议 15-20%
成熟店铺 5-10%
```

### 🔟 退货损耗
```
= 建议售价 × 退货率
假设 1-3% 商品会被退回
平均损耗成本
```

## 模板中的三个定价选项

### 💰 定价 1：保本售价

**定义**：仅能收回所有成本的最低价格

**公式**：
```
保本售价 = 所有成本 / (1 - 平台费率 - 手续费率 - 增值税率)
```

**说明**：
- 低于这个价格就会亏损
- 不能作为实际定价
- 用来确定价格下限

**示例**：
```
成本 120¥
保本价 180¥

= 120 / (1 - 0.05 - 0.02 - 0.03)
= 120 / 0.90
= 133¥
```

---

### 📌 定价 2：建议售价（**最重要**）

**定义**：考虑市场竞争和合理利润的建议价格

**计算逻辑**：
```
建议售价 = 保本售价 × (1 + 利润率)

其中利润率根据：
- 新品/差异化品：30-50%
- 竞争品：15-25%
- 爆款/走量品：5-15%
```

**如何使用**：
1. 首先看"保本售价"确定下限
2. 再看"建议售价"的建议利润率
3. 根据竞争情况调整
4. 最终定价在"建议价"上下浮动 5-10%

**示例**：
```
保本价：133¥
建议利润率：30%
建议售价：133 × 1.3 = 173¥

实际可定价：165-180¥
```

---

### 🎯 定价 3：竞争对标价

**说明**：
- 不在模板计算内
- 需要自己去 TikTok 查询竞品
- 参考竞品价格微调

**步骤**：
```
1. 搜索你的商品关键词
2. 找到前 5 个销量好的竞品
3. 记录他们的价格
4. 计算平均价格
5. 你的定价在平均价 ±5% 内
```

## 修改和调整

模板中的"可修改项"和"自动计算项"：

| 项目 | 可修改? | 说明 |
|------|--------|------|

## 常见问题

### Q1：为什么定价比竞品贵这么多？

**可能原因**：
- ❌ 输入的成本太高了（确认一下）
- ❌ 广告预算设置太高了（改小）
- ❌ 退货损耗率太高（改小）
- ✅ 商品质量确实更好（可以高价）

**解决**：
```
1. 检查输入数据是否准确
2. 降低广告预算比例
3. 降低退货率预期
4. 查看竞品成本是否比你低
```

---

### Q2：为什么有的国家利润这么低？

**可能原因**：
- 菲律宾费率高（最高 20.5%）
- 越南增值税高（10%）
- 关税高的品类

**解决**：
```
1. 选择费率低的国家（新加坡、泰国）
2. 选择低关税品类
3. 提高销量来分摊成本
4. 优化供应链降低采购成本
```

---

### Q3：定价不能超过 xxx 元，怎么办？

**市场定价限制**：
```
如果消费者只能接受 100¥
但建议售价是 150¥

说明这个商品：
❌ 在这个国家不赚钱
❌ 不适合销售到这个国家
✅ 需要降低成本
```

**解决方案**：
```
1. 找更便宜的供应商（便宜 10¥）
2. 精简包装，减轻重量（省运费）
3. 减少国内运费（集中发货）
4. 改为销售其他国家
```

---

### Q4：可以做团购吗？组合销售呢？

**模板支持**：
```
针对每个 SKU 单独计价
组合产品需要拆分计算
```

**例子**：
```
单件 T 恤：25¥ + 2¥ + ... = 50¥成本
定价：100¥

两件套：50¥×2 = 100¥成本
定价：180¥（团购优惠 10%）
```

---

### Q5：我想增加 SKU，需要重新计算吗？

**建议方法**：
```
复制一个新的计算行
改动采购成本和重量
其他自动计算

同类商品通常有规律：
- 同材料，不同尺寸：重量差异小
- 同品类，不同型号：成本和重量差异
```

## 定价更新频次

### 建议更新周期

| 项目 | 更新频次 | 原因 |
|------|--------|------|
| 采购成本 | 每次进货更新 | 成本可能有浮动 |
| 物流费 | 每月确认 | 运费可能调价 |
| 竞品价 | 每周检查 | 竞争对手可能降价 |
| 平台费 | 每季度确认 | 通常不变但有优惠活动 |
| 关税 | 品类变化时 | 进口政策可能改变 |
